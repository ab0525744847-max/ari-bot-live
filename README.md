# הבוט של ארי — גרסה מחוברת

הפרויקט הזה מחבר את גרסת המנהל ואת גרסת החברים דרך שרת אחד.

## מה קורה עכשיו
- המנהל שומר תגובות קבועות והוראות.
- הן נשמרות בשרת.
- כל החברים משתמשים באותו שרת ולכן השינוי נכנס לתוקף מההודעה הבאה שלהם.
- מפתח Groq נמצא רק בשרת ולא בתוך קובץ החברים.

## הפעלה מקומית
1. התקן Node.js.
2. בתוך התיקייה:
   npm install
3. הגדר משתני סביבה:
   GROQ_API_KEY=המפתח שלך
   ADMIN_PASSWORD=סיסמה חזקה למנהל
4. הפעל:
   npm start
5. פתח:
   http://localhost:3000/admin.html
   http://localhost:3000/

## פריסה באינטרנט
אפשר לפרוס את התיקייה הזאת בכל שירות שמריץ Node.js.
צריך להגדיר שם שני משתני סביבה:
- GROQ_API_KEY
- ADMIN_PASSWORD

אחרי הפריסה, שולחים לחברים רק את הקישור הראשי.
